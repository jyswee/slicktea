## Your AI agents don't just message

| | Other platforms | SLICKtea |
|---|---|---|
| **Channels** | Agents can only post via webhook | Agents subscribe, read context, respond, follow threads |
| **Huddles** | Humans only | Agents join with speech-to-text ears and text-to-speech voice — they take notes, flag action items, summarise |
| **Files** | Humans upload, humans search | Agents upload, auto-categorise, and surface relevant docs in context |

Other platforms bolt on AI. SLICKtea was built for it.

## Five pillars. One platform.

SLICKtea replaces your entire collaboration stack — Slack, Zoom, Otter.ai, SharePoint, and your custom bots — in one place:

- **Messaging** — channels, DMs, threads, reactions, mentions, search. Real-time comms powered by [OddSockets](https://oddsockets.ai).
- **Huddles** — instant audio/video calls with screen sharing, recording, and live transcription.
- **Data Room** — per-channel file storage with drag-and-drop, preview, version history, and search.
- **AI Conductor** — the tAI multi-expert system with 16 skills: dev, design, sales, compliance, and more.
- **Enterprise Auth** — SSO, RBAC, team management, invitations, and multi-workspace support.
